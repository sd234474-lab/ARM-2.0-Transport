## Что ещё нужно подтвердить до любых установочных действий

1. Владелец идентифицирует используемый вариант АРМ 1.0 и выбранную БД из фактически найденных вариантов; если есть ещё установки/службы/контейнеры, они добавляются в ProtectedRoots и inventory.
2. По отдельному разрешению обеспечить согласованный backup: действующая SQLite DB вместе с WAL/SHM при наличии (SQLite-aware backup при работающей системе), registry TEST-launcher, конфиги/.env с секретами в защищённом хранилище, соответствующие app/release/зависимости, launcher scripts/ярлыки; если используется PostgreSQL — штатный dump и версия server/extensions, не простая копия live PGDATA.
3. Проверить доступность копий, их manifest/checksum, DB integrity; **восстановить в отдельное одноразовое место**, открыть совместимым приложением/проверить данные по отдельному разрешению. Наличие файла само по себе — не проверка restore. Ничего не восстанавливать поверх работающего экземпляра; текущие старые копии не дают GO.
4. Владелец выполняет baseline АРМ 1.0: штатный запуск, логин, открытие заранее выбранной тестовой карточки, контролируемое сохранение, повторное открытие/доступ к данным. Записать фактическую DB/URL, результат и контрольные отпечатки конфигов. На время UAT без сознательных операций в ARM1 его файлы/данные должны оставаться неизменными; собственные разрешённые baseline saves учитывать отдельно.
5. После каждого будущего start/stop/cleanup UAT повторить те же baseline проверки и отдельно доказать **одновременную** работу. Любой сбой ARM1 = STOP, сначала остановить только принадлежащий UAT, сохранить диагностику; восстановление ARM1 — отдельное ручное решение, не автоматический rollback из этого пакета.

Повторный read-only осмотр: `inventory.ps1 -ProtectedRoot <фактические каталоги>`; stdout можно сохранить в локальное защищённое evidence. Ошибки/UNKNOWN не трактуются как отсутствие ресурсов. Script не выводит конфигурационные значения, task arguments или credential hashes. Для внешних/иначе названных startup механизмов нужна ручная сверка; запуск/остановка приложения, копирование/restore и ввод credentials этой инвентаризацией не разрешены.
